# Quran Study App

A bilingual Quran study app built with Next.js, TypeScript, and Tailwind CSS.

## Features
- English + Urdu toggle
- Quranic Arabic text
- Verse search by keyword and theme
- Topic-based research
- Research summary builder
- Rule / instruction / prohibition grouping
- Topic comparison
- Keyword clusters
- Term glossary with classical meanings
- Scholar notes and historical context support

## Run locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Build for production

```bash
npm run build
npm run start
```

## Downloadable project note
This project is saved in your GitHub repository and can be cloned or downloaded as a ZIP from GitHub.

## Quick user guide
1. Open the app in the browser.
2. Use the search box to find a verse or topic.
3. Click a verse card to open the verse details.
4. Use Research Topic to find related verses by subject.
5. Use Research Summary to view rules, methods, prohibitions, principles, and historical context.
6. Use Quranic Terms to study word meanings and classical explanations.
7. Toggle between English and Urdu with the top-right button.
8. Use Topic Comparison and Keyword Clusters for deeper study.
